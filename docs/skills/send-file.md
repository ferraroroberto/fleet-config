# Sending a file to the owner (`send_file.py`)

`skills/_lib/send_file.py` is the any-harness half of app-launcher's outbox: it POSTs a path to the caller's own launcher session (`APP_LAUNCHER_SESSION_ID`) over loopback and prints one result line — `SENT=<id>` (exit 0), `REFUSED=<reason>: <message>` (exit 1, the launcher's own reason: `out_of_root`, `too_large`, `type_not_allowed`, …) or `UNAVAILABLE=<reason>` (exit 2: no launcher session, launcher down, session-host down, endpoint missing, unreadable reply, timeout). Only an accepted entry id is ever `SENT`. It re-implements no file rule — the launcher owns the allowed roots, size, type and content checks. The usage wording lives once, in `global-CLAUDE.md` ("Showing the owner a file"); skills point there rather than restate it. Tests: `tests/test_send_file.py`.
