# `/perf-review`

- **`/perf-review <repo> [file]`** — how fast a running fleet web app loads **on a phone**: a Playwright phone-profile load (iPhone WebKit cold, reported only; Android Chromium cold + warm, CDP-throttled to `budgets.toml`'s phone profile) and GET-only endpoint timing at the app's own poll spacing, scored against versioned budgets, mapped to the patterns in `skills/perf-review/playbook.md` (each with its app-launcher evidence and rough LOC), ranked by gain per line of code. Read-only: never starts, restarts or kills the app; a dead port is `unmeasured`. Every run appends one record per app to the machine-local ledger `~/.claude/hooks/state/perf-review/ledger.jsonl` (schema in `skills/perf-review/SKILL.md`; app-launcher's Apps section reads it). `file` opens or updates the one managed `perf-review: phone-load findings` issue only while a budget is over or a `## Fixes` item is open, and closes it on a green run with no open item; an `unmeasured` run leaves it alone (numbers and paths only; its `## Fixes` checklist is kept verbatim across runs). On demand; `/perf-sweep` runs it weekly over every web app ([perf-sweep](perf-sweep.md)).
