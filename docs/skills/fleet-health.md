# `/fleet-health`

- **`/fleet-health`** — the **hardware lens**: a weekly checkup of what every machine in the fleet is actually carrying, kept as one *incremental ledger* so the useful question — "what crept in since last week?" — is answerable at a glance. Machine discovery is dynamic and **no machine name appears in the skill**: `capture.py` reads the fleet from the hub's own inventory (`GET /admin/api/machines/status`) and routes each box by *probed capability*, never by id — a host on loopback, a peer at its declared LAN address (resolved from the hub's `models.yaml` `hosts:` block, since the inventory carries no address), and anything that can't be measured recorded as **not covered with a reason** rather than silently dropped. Captures are strictly local to each hub by design (each host's hub owns its own sampler; the diagnostics engine exposes no `machine_id`), so every machine is driven through its own `/admin/api/diagnostics/*`; all captures start before any is polled, then the helper **blocks to completion** in bounded chunks — never background-and-wait (fleet-config#314) — treating the hub's `409` as "busy, adopt the in-flight run" rather than a failure. The analysis pass is deliberately **adversarial**: it cross-checks per-app CPU against the system-wide figure, peak RSS against total RAM, and asks what is *resident but idle*, because the dry run that motivated the skill found engine bugs and ~4 GB of unused TTS engines while VRAM, not RAM, was the real constraint. Entries follow a fixed Machine · Date · Findings · Annex · Recommendation shape so runs stay diffable, and a recommendation still open from last week is carried forward explicitly, never silently re-derived. The ledger + per-run annexes live under `~/.claude/fleet-health/` — user-local, **never committed** (it is an inventory of the user's own hardware), following `/insights-weekly`'s precedent; only the skill and its runner are public. Reports out to Telegram, with a private Artifact as best effort. Built to run unattended on a weekly app-launcher job. Built in #397.
