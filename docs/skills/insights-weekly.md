# `/insights-weekly`

- **`/insights-weekly`** — turn Claude Code's built-in **`/insights`** report into a week-over-week signal. `/insights` already writes a dated, self-contained `report-<timestamp>.html` into `~/.claude/usage-data/` on every run, so that series *is* the history; this skill refreshes it, hands the **newest two reports to the local LLM hub** (`127.0.0.1:8000`, via `report.py` + `extract.py`) to narrate what changed — no raw-JSON re-aggregation, and the orchestrator doesn't write the narrative itself. The result is saved as a dated, traceable note under `~/.claude/usage-data/weekly/` (user-local, never committed) and a concise digest is posted to Telegram. First run captures a baseline instead of a diff; model is `INSIGHTS_DIFF_MODEL`-overridable (default `claude_sonnet`). Built to run unattended on a weekly app-launcher job (first run targeted for a Friday).
